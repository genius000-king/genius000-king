# لوحة المشرف — aboal3z.dzn

لوحة ثابتة بالكامل: صفر بناء، صفر تبعيات.

## الرفع

ارفع محتويات هذا المجلد في **مسار منفصل** عن موقع العملاء — مثل
`/admin` أو نطاق فرعي `panel.example.com`.

الملف `index.html` يحمل `noindex, nofollow` فلا تظهر اللوحة في نتائج
البحث.

## حسابك

اللوحة لا تسمح بالتسجيل الذاتي — الحساب يُنشأ يدوياً مرة واحدة من
لوحة Supabase:

**Authentication ← Users ← Add user ← Create new user**
اكتب بريدك وكلمة مرور، وفعّل **Auto Confirm User**.

تغيير كلمة المرور لاحقاً من نفس المكان.

## الأقسام

| القسم | ماذا يفعل |
|---|---|
| لوحة القيادة | أرقام سريعة، آخر الطلبات، وفحص جاهزية الموقع |
| الطلبات | بحث وفلترة، تفاصيل، تغيير حالة، رد واتساب بنقرة، تصدير CSV |
| نصوص الموقع | كل كلمة في الموقع، مجمّعة حسب القسم |
| الأعمال | المعارض والأعمال، سحب لإعادة الترتيب، رفع صور |
| البكجات | البكج ← الكتل ← الصور، مع التحكم الكامل في تقسيمة البينتو |
| الكتالوج | بنود الطلب، الخدمات، خطوات العمل، طرق الدفع، الآراء |
| الألوان والخط | ألوان الهوية والمقاسات وشدّة الحركة، بمعاينة حيّة |
| ترتيب الأقسام | سحب لتغيير ترتيب الصفحة، وإظهار وإخفاء |
| معاينة الموقع | الموقع داخل إطار معزول بقياسات أجهزة حقيقية |
| الإعدادات | التواصل، **قالب رسالة واتساب**، SEO، الحساب |

## تقسيمة البكج

**البكجات ← افتح بكجاً ← افتح كتلة**

تحصل على معاينة حيّة بنفس الخوارزمية التي يعمل بها الموقع. اضغط أي صورة
لتختار مقاسها من عشرة مقاسات، وتحتها النمط وعدد الأعمدة وارتفاع الصف
والمسافة. ما تراه هنا هو ما يراه الزبون حرفياً.

## رسالة واتساب

**الإعدادات ← رسالة واتساب**

تحرّر صيغة الرسالة التي تصلك عند كل طلب. المتغيّرات تُدرَج بضغطة، والمعاينة
تتحدّث فوراً بمثال حقيقي، وزر يجرّبها على واتساب مباشرة.

`{{#attachments}}…{{/attachments}}` يُظهر القسم فقط عندما توجد مرفقات.

## الحفظ

كل تعديل يُحفظ تلقائياً، ومؤشّر الحالة في الشريط العلوي يخبرك: يحفظ ←
تم الحفظ. حذف عنصر يحمل أبناءً يطلب كتابة اسمه للتأكيد، وزر التراجع
يعيد آخر عشر عمليات.
