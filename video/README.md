# كيف تتخزّن المعلومات — فيلم توضيحي

فيلم عربي (RTL) مدته **15:55** عن التخزين الفيزيائي للمعلومات: القرص الصلب،
القرص الضوئي، الذاكرة الصلبة، الرام، وأخيرًا المخ.

مبني بـ [Remotion](https://remotion.dev) — كل إطار مكوّن React، لا محرر فيديو.

---

## التزامن مع الصوت

الفيلم **بلا صوت مدمج**، وهذا مقصود. كل مشهد مثبّت على الإطار الدقيق المشتق من
التايم-ستامبس في `src/script/transcript.ts`. ضع تسجيلك الصوتي فوق الفيديو في أي
محرر ابتداءً من `00:00` — سيتزامن دون ضبط.

لدمج الصوت مباشرة:

```bash
/opt/pw-browsers/ffmpeg-1011/ffmpeg-linux \
  -i out/storage-film.mp4 -i voice.wav \
  -c:v copy -c:a aac -b:a 192k -shortest out/final.mp4
```

## إعادة تجميع الأجزاء

الفيلم الكامل ٢١٢ ميغا، وحد الرفع في المحادثة ٣٠ ميغا — لذلك يُسلَّم مقسّمًا
إلى تسعة أجزاء بجودة كاملة (بلا أي ضغط إضافي، حدود الأجزاء مضبوطة على الإطار).

لإعادة تجميعها في ملف واحد:

```bash
# على ويندوز/ماك/لينكس، بعد تنزيل الأجزاء في مجلد واحد
for f in part-*.mp4; do echo "file '$f'"; done > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy storage-film.mp4
```

أو ببساطة: أعد التصيير محليًا — المشروع يعيد إنتاج نفس الفيلم بايتًا ببايت.

## قواعد ثابتة في هذا المشروع

1. **لا `letter-spacing` موجب على نص عربي.** العربية خط متصل، وأي تباعد يفكّ
   تشبيك الحروف. التراتبية تأتي من الوزن واللون والخطوط الفاصلة.
2. **لون واحد = معنى واحد** طوال الفيلم: أحمر دافئ = قطب شمالي، أزرق بارد =
   قطب جنوبي، أحمر = ليزر، أخضر مزرقّ = شحنة، بنفسجي = المخ.
3. **عنصر أو عنصران متحركان في اللقطة الواحدة.** الحركة النادرة هي ما يجعل
   العمل يبدو مكلفًا.
4. **التوقيت يُعدَّل في مكان واحد** — `Video.tsx`، بصيغة `'م:ث'` كما يُقرأ النص.

## تصحيحان على النص الأصلي

| الوقت | في التسجيل الصوتي | في الصورة |
|-------|-------------------|-----------|
| `1:00` | «شمالي يرمز له بـ S وجنوبي بـ N» | **N = شمالي، S = جنوبي** — الرموز مقلوبة في الصوت |
| `4:42` | الحفرة «تحجب الضوء» | الحفرة عمقها `λ/4`، فالموجة العائدة تلغي جارتها — **تداخل هدّام** |
