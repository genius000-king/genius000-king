# قاعدة البيانات

ثلاثة ملفات تُشغَّل بالترتيب في **Supabase ← SQL Editor**:

| # | الملف | ماذا يفعل |
|---|---|---|
| 1 | `01-schema.sql` | ينشئ 14 جدولاً ومحفّزات `updated_at` |
| 2 | `02-security.sql` | يفعّل RLS ويكتب السياسات وينشئ حاوية `media` |
| 3 | `03-seed.sql` | يزرع مفاتيح النصوص وترتيب الأقسام وقالب واتساب |

الثلاثة **آمنة لإعادة التشغيل** — لن تكرّر ولن تحذف.

## ما لا يزرعه `03-seed.sql` عمداً

لا أعمال ولا بكجات ولا آراء وهمية. تلك تُضاف من لوحة التحكم ببياناتك
الحقيقية، فلا يخرج الموقع للناس ومحتواه تجريبي.

## نموذج الأمان

المفتاح `anon` مفتاح **عام** مصمَّم ليعيش في المتصفح. حمايتك الحقيقية
هي RLS في `02-security.sql`:

- **الزائر** يقرأ المحتوى `published = true` فقط، ويُنشئ طلباً، ويرفع
  مرفقات داخل `orders/` — ولا يقرأ الطلبات ولا يعدّل شيئاً.
- **المشرف** (مستخدم مسجَّل الدخول) يقرأ ويكتب كل شيء.

قيود إضافية على إنشاء الطلب: طول الاسم والتواصل والوصف مقيّد،
و`status` يُجبَر على `new` — فلا يستطيع أحد حقن طلب «منجز».
