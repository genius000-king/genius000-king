# General artifact profile

Use for tasks outside software, games and animation. Derive a domain-specific pipeline from the requested outcome rather than forcing every project into a code repository.

Define the deliverable format, intended audience/use, source inputs, quality references, required tools and a way to evaluate the actual artifact. Separate explicit scope, reasonable assumptions and optional expansions.

Identify major risks, build a representative end-to-end sample, then divide independent work around stable interfaces and coherent ownership. Use the coordinator, worker, reviewer and integration responsibilities where they add value.

Preserve editable sources and provenance. Record evidence, costs, limitations and reconstruction instructions. Use available real tools; if the domain requires unavailable physical equipment or professional evaluation, identify the exact gap and complete useful independent work without inventing a result.
