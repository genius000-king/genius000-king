# Game profile

Read `examples/game-production.md`. Define the intended player experience, complete core loop, camera, controls, target platforms, art direction, audio references and performance targets.

Choose a coherent playable milestone while preserving the full vision. Prove engine/toolchain, one representative asset import, interaction events and packaging before bulk asset generation. Use a custom engine when justified by the goal and budget.

Coordinate gameplay, animation, environment, lighting, UI, audio and performance through shared scale, naming, materials, skeletons, events and resource budgets. Assign complete subsystems/scenes to workers, with detailed criteria inside them.

Evaluate actual play, visual continuity, input feedback, audio in context, save/restart behavior and target-device frame/memory profiles. Pure code inspection cannot establish fun or responsiveness.

Deliver editable engine/source project, assets and provenance, playable build when supported, controls, build instructions, representative recordings, evidence and limitations.
