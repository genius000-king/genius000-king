# Film, animation and cartoon profile

Produce a coherent audiovisual work through a shared creative and technical pipeline. Distinguish a script, animatic, finished shot and finished film in every status report.

## Preproduction

Extract intended audience, story, emotional arc, approximate duration, visual style, aspect ratio, frame rate, output resolution, dialogue language and sound expectations. Infer reversible missing preferences and record them. Preserve the user's explicit choices.

Create a story treatment, script, character/style bible, shot list and storyboard or animatic. Fix continuity rules: character proportions, palette, environment scale, costume, lighting logic, screen direction, camera vocabulary, voices and music direction.

Do not use endless verbal critique as a substitute for a representative shot. Produce a short technical/style proof that exercises asset generation/import, rigging if applicable, motion, lighting, render/composite and sound. Inspect it before expanding production.

## Production

Choose tools actually available: a 2D/3D application, procedural animation, image/video generation, voice/music generation or licensed/source assets as the project permits. Verify GUI/headless support, export capabilities and local GPU availability. If the host has Blender, inspect its actual version and interfaces rather than assuming an API.

Use coherent shot/sequence ownership. Workers receive shot IDs, script beats, character references, duration/frame range, incoming/outgoing continuity, camera plan, asset IDs and export settings. Shared characters/rigs/materials have a single versioned owner.

Parallelize independent asset creation and shots only after these contracts exist. Keep editable source files, generation settings/seeds where supported, rig/animation data and compositing files. Do not let independent workers redesign the same character.

## Review and integration

Review story clarity, poses/silhouette, motion arcs and timing, lip sync if required, intersections/contact, flicker, temporal consistency, lighting, continuity, framing, text, audio synchronization and mix.

Inspect representative frames and the complete export at playback speed. A few attractive stills cannot verify animation. Signal checks can reveal clipping or missing audio but do not establish artistic quality; use actual listening when available and report missing capability.

Integrate approved shots in a master timeline. Review cuts, pacing, dialogue/music levels, transitions, beginning/end frames, codecs and the final export. Measure render cost on a representative shot before admitting an expensive full render.

Deliver the final video when feasible, editable project and timeline, source assets, audio/stems as applicable, captions when requested, render/export instructions, asset provenance, evidence and remaining limitations. If only a preview/animatic can be completed, label it accurately and preserve the path to the requested final work.
