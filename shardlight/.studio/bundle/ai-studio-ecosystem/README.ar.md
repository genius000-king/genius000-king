# حزمة AI Studio Ecosystem

ارفع هذا الملف المضغوط إلى وكيل لديه وصول للملفات وأدوات التنفيذ، ثم أرسل نص [PROMPT.ar.txt](PROMPT.ar.txt) بعد وضع فكرتك في آخره. نقطة الدخول للوكيل هي [START_HERE.md](START_HERE.md).

لا تحتاج ملء القوالب بنفسك. الوكيل يستخرج المتطلبات من فكرتك، يفحص البيئة، يجهز المشروع، يختار مسار العمل، ويستخدم الوكلاء والأدوات المتاحة. يحفظ التفاصيل والحالة والأدلة ويواصل العمل المصرّح به.

## المحتويات

- جميع ملفات الحزمة السابقة، ومنها [SKILL.md](SKILL.md) و[الدليل المفصل](GUIDE.ar.md) والقوالب والمصادر والأمثلة.
- [نقطة بدء](START_HERE.md) واحدة وبرومبت عربي جاهز.
- أدوار المدير والمنفّذ والمراجع ومسؤول الدمج.
- مسارات [البرامج](profiles/software.md) و[الألعاب](profiles/game.md) و[الأفلام والتحريك](profiles/animation.md) و[الأعمال الأخرى](profiles/general.md).
- إجراءات التنفيذ وإدارة السياق والتسليم داخل `playbooks/`.
- أداة Python محلية داخل `bin/` لإنشاء المشروع، وحفظ الحالة، وفحص علاقات المهام والأدلة، وتوليد سياق مختصر، وتجميع الملفات المختارة.
- اختبارات للأداة داخل `tests/`.

## حدود واضحة

الحزمة تستخدم قدرات المنصة التي تشغّلها. لا تمنح النموذج تحكمًا في جهاز غير متاح، ولا وصولًا إلى نماذج مدفوعة، ولا استمرارًا بعد إغلاق جلسة لا تدعم الاستئناف التلقائي. التشغيل أيامًا يحتاج منصة أو مشغّلًا يبقيه يعمل ويستأنف حالته.

أداة Python ليست مشغّل نماذج أو خدمة خلفية، ولا تعتبر وجود ملف دليل إثباتًا لجودة محتواه. الوكلاء يشغّلون الأدوات الحقيقية ويفحصون الناتج. القيم المسجلة للتكلفة توثيقية؛ حدود الإنفاق الفعلية تتطلب دعمًا من المزوّد أو المشغّل.

## استئناف مشروع سابق

أعطِ الوكيل مجلد المشروع والحزمة، ثم استخدم `RESUME_PROMPT.txt` الذي يولّده مساعد الحزمة عند حفظ نقطة الاستئناف. يتأكد الوكيل من حالة الملفات والنسخ قبل المتابعة.

الحزمة لا تضمن نتيجة بمستوى استوديو تجاري من كل فكرة أو خلال مدة ثابتة. هي نظام عمل قابل للتجربة والتحسين، ويمكنك قياسه على مشروعك الحقيقي.
