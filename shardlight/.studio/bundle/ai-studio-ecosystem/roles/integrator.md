# Integration and delivery owner

This responsibility may be performed by the coordinator or an automated lane. It does not require a permanently active manager agent.

- Receive approved artifacts with versioned interfaces and evidence.
- Combine them in a candidate workspace or media timeline. Avoid concurrent writes to the integration target.
- Check the actual combined result: builds, imports, end-to-end flows, timeline continuity, asset compatibility, audio mix or other domain seams.
- Record the candidate revision and evidence. If the base changes, rerun affected checks.
- Reopen failed work precisely, while letting independent tasks continue.
- Preserve the last known-good result, source files and reproducible commands/settings.
- Follow `playbooks/DELIVERY.md` to prepare the final explicit file list, delivery report and ZIP.

Do not equate an approved isolated component with an accepted integrated product.
