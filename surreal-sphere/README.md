# الكرة السريالية · Surreal Sphere

فيديو تجريدي مدته 30 ثانية بدقة ‎1280×720‎ (16:9 لليوتيوب، 30 إطاراً في الثانية) مع موسيقى. كل لقطة فيه مولّدة بالكود، بلا أي أصول جاهزة ولا ذكاء اصطناعي توليدي.

## القصة (تحوّل واحد متصل)

| الزمن | ما يحدث |
|---|---|
| 0 – 2.2 ث | فراغ أبيض لا نهائي وأرضية بيضاء ممتدة |
| 2.2 – 5.2 | الأرض تنحني للداخل مثل تشوّه في الزمكان |
| 4.8 – 8.2 | مادة الأرض تُسحب للأعلى في عمود مطاطي، ثم ينقطع عنقه فتولد الكرة |
| 8.2 – 12.2 | كرة سائلة حيّة تتنفّس، تتحول من الأحمر إلى الأخضر ثم الأزرق ثم ألوان غريبة |
| 9.7 – 12.2 | يد من جسيمات هندسية تتشكّل من الأرض وتمتد نحو الكرة |
| 12.2 | القبضة: الضوء يخفت والكرة تقاوم |
| 13.6 – 17.0 | **اللقطة المرجعية**: نفس زاوية الصورة المرسلة وتكوينها، وأيدٍ أخرى تنبثق في الخلفية |
| 17.0 – 21.7 | الأيدي تندفع وتمسك الكرة واحدة تلو الأخرى، والمقاومة والارتجاف والتشوّه في تصاعد |
| 23.7 – 24.2 | شهيق: كل شيء ينضغط ويصمت |
| 24.2 | انفجار يفتّت كل الأيدي إلى ملايين القطع |
| 24.2 – 30 | الجسيمات تتناثر في فراغ أبيض، ثم يبهت المشهد إلى البياض |

الأزمنة كلها في ملف [`timeline.json`](timeline.json)، والصورة والموسيقى تقرآن منه، فالتزامن بينهما دقيق.

## كيف بُني

- **العالم** ([`shaders.js`](shaders.js)): حقل مسافات موقّعة (SDF) واحد يُرسم بالـ ray marching، ويضم الأرضية والكرة وعنق الانفصال والأكمام السائلة حول الأذرع. لأنه حقل واحد، يأتي كل تحوّل متصلاً بطبيعته.
- **الأيدي** ([`scene.js`](scene.js)): نموذج يد بشرية من كبسولات، بعظام ومفاصل وأصابع تلتف حول الكرة بحلّ تصادم. الأيدي مغطاة بنحو 230 ألف جسيم، كل جسيم مجسّم هندسي حقيقي (مكعب مشطوف، رباعي أوجه، ثماني أوجه، بلاطة، شظية) يُرسم بتتبّع الأشعة داخل نقطة.
- **الكاميرا**: لقطة البطل محسوبة رياضياً من قياسات الصورة المرجعية: خط الأفق عند 69% من ارتفاع الإطار، وموضع الكرة وحجمها، والأيدي الخلفية في نفس بكسلاتها.
- **ما بعد المعالجة**: عمق ميدان، توهّج، تدرّج لوني سينمائي (ACES)، زيغ لوني، موجة صدمة، وحبيبات فيلم.
- **الموسيقى** ([`music.py`](music.py)): مركّبة من الصفر بـ numpy/scipy، وتمر بهذه المراحل: همس الفراغ ← طنين الجاذبية ← شدّ مطاطي ← فرقعة الانفصال ← أربيجيو منوّم ← ضربة القبضة ← نبض قلب ← طبول ورفّات مع كل قبضة ← شهيق ← انفجار ← جوقة الختام.

## التشغيل

```bash
npm install          # three.js
./build.sh           # يرسم الفيديو ويركّب الموسيقى ويُخرج out/surreal-sphere-720p.mp4
```

الرسم يعمل على المعالج (SwiftShader عبر Chromium بلا واجهة)، ويستغرق نحو ساعتين للفيديو كاملاً. لمعاينة لقطات منفردة:

```bash
node render.mjs stills 8.2,15.4,24.5 out/stills
```

## ملاحظة صريحة

اللقطة المرجعية تطابق الصورة في الزاوية والتكوين والإضاءة العامة وتوزيع الألوان والعناصر. أما الواقعية الفوتوغرافية للصورة (وهي مولّدة بالذكاء الاصطناعي) فلا يصلها رسم برمجي يعمل لحظياً على المعالج.
