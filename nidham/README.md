# NIDHAM · نِظام

**تقويم + قائمة مهام في واجهة واحدة.** بلا حساب، بلا خادم، بلا تتبّع — كل شيء يُحفظ في متصفحك.
*A calendar and a to-do list in one surface. No account, no server, no tracking — everything lives in your browser.*

![lavender haze · soft graphite](https://img.shields.io/badge/palette-%2392A9E1%20%C2%B7%20%232B2B2B-92A9E1)

---

## التشغيل | Run

```bash
# أبسط طريقة: افتح الملف مباشرة
open nidham/dist/index.html          # ملف واحد مستقل، يعمل بلا إنترنت

# أو شغّل النسخة المفكّكة (تحتاج خادمًا محليًا لتفعيل العمل دون اتصال)
npx http-server nidham -p 8080
```

النسخة داخل `dist/` ملف HTML واحد (‏~70KB) يحوي كل شيء — انسخه على أي جهاز أو استضفه على GitHub Pages.

## ما الذي يميّزه | What it does

| | |
|---|---|
| **ثلاث عروض** | شهر · أسبوع · قائمة قادمة — بمفاتيح `M` / `W` / `A` |
| **إضافة بلغة طبيعية** | `اجتماع 3م غدا !مهم #عمل` ← موعد، غدًا، 15:00، أولوية عالية، تصنيف "عمل" |
| **مهام ومواعيد** | المهمة تُنجَز، الموعد له وقت بداية ونهاية — نوعان بواجهة واحدة |
| **تكرار ذكي** | عند إنجاز مهمة متكرّرة يُولَّد التالي تلقائيًا (يومي · أيام عمل · أسبوعي · شهري) |
| **سحب وإفلات** | اسحب أي مهمة إلى يوم آخر في التقويم لإعادة جدولتها |
| **تراجع** | كل حذف/إنجاز/نقل قابل للتراجع من شريط التنبيه |
| **مقاييس** | نسبة إنجاز اليوم، سلسلة الأيام المتتالية، المتأخّر |
| **عربي/إنجليزي** | تبديل فوري مع انعكاس كامل للاتجاه (RTL/LTR) |
| **ليل/نهار** | لوحتان من نفس هوية الألوان |
| **تصدير** | نسخة JSON كاملة، أو ملف `.ics` يُستورد في تقويم آبل/جوجل |
| **يعمل بلا إنترنت** | Service worker + manifest — قابل للتثبيت كتطبيق على الهاتف |

### اختصارات لوحة المفاتيح

| المفتاح | الفعل |
|---|---|
| `N` | عنصر جديد |
| `/` أو `Ctrl/⌘ + K` | بحث في كل شيء |
| `T` | العودة إلى اليوم |
| `←` / `→` | الشهر (أو الأسبوع) السابق/التالي |
| `M` `W` `A` | شهر / أسبوع / قائمة |
| `Esc` | إغلاق أي نافذة |

## البنية | Architecture

```
nidham/
├── index.html              الهيكل فقط — لا منطق
├── assets/css/app.css      متغيّرات لونية + سِمتان (نهار/ليل)
├── assets/js/core.js       تواريخ + ترجمة + مخزن + محلّل اللغة الطبيعية
├── assets/js/ui.js         طبقة عرض خالصة: حالة ← DOM
├── assets/js/app.js        ربط الأحداث، النوافذ، السحب، النسخ الاحتياطي
├── sw.js                   تخزين مؤقّت للعمل دون اتصال
├── tools/build.py          يدمج كل شيء في ملف واحد
└── dist/index.html         الناتج: ملف مستقل
```

**قرارات تصميمية مقصودة:**

- **بلا إطار عمل ولا خطوة بناء.** جافاسكربت عادية (ES5-ish) — يفتح في أي متصفح، ويظل مقروءًا بعد سنة.
- **`localStorage` لا قاعدة بيانات.** الملكية الكاملة للبيانات مقابل عدم المزامنة بين الأجهزة — والتصدير يسدّ الفجوة.
- **التواريخ نصوص `YYYY-MM-DD` بتوقيت محلي.** لا `Date.toISOString()` — لأنه ينقل اليوم للخلف في التوقيتات الموجبة.
- **`\b` لا يعمل مع العربية في جافاسكربت** (حدود الكلمات ASCII فقط)، لذا يستخدم المحلّل `(?:^|\s)…(?=\s|$)`.
- **`<bdi>` حول كل رقم ووقت** حتى لا يعكس محرّك الاتجاه ترتيب "3:00 PM – 4:00 PM" داخل نص عربي.

### حدود معروفة | Known limits

- لا مزامنة بين الأجهزة (بالتصميم). النقل يتم بملف النسخة الاحتياطية.
- التكرار يُولّد النسخة التالية عند الإنجاز فقط، لا سلسلة لا نهائية مسبقة.
- تصدير `.ics` باتجاه واحد: لا استيراد من تقويم خارجي بعد.
- مسح بيانات المتصفح يمسح كل شيء — صدّر نسخة بين حين وآخر.
