# NIDHAM · نِظام

**تقويم + قائمة مهام في واجهة واحدة.** بلا حساب، بلا خادم، بلا تتبّع — كل شيء يُحفظ في متصفحك.
*A calendar and a to-do list in one surface. No account, no server, no tracking — everything lives in your browser.*

![lavender haze · soft graphite](https://img.shields.io/badge/palette-%2392A9E1%20%C2%B7%20%232B2B2B-92A9E1)

---

## التشغيل | Run

```bash
# أبسط طريقة: افتح الملف مباشرة
open nidham/dist/index.html          # ملف واحد مستقل، يعمل بلا إنترنت

# أو شغّل النسخة المفكّكة (تحتاج خادمًا محليًا لتفعيل العمل دون اتصال)
npx http-server nidham -p 8080
```

النسخة داخل `dist/` ملف HTML واحد (‏~70KB) يحوي كل شيء — انسخه على أي جهاز أو استضفه على GitHub Pages.

## ما يفعله | What it does

| | |
|---|---|
| **عرضان** | شهر (نقاط لا نصوص) · قائمة قادمة — يُبدَّل من زر واحد |
| **إضافة بلغة طبيعية** | `اجتماع 3م غدا !مهم` ← غدًا، 15:00، أولوية |
| **تكرار** | إنجاز المهمة المتكرّرة يولّد نسختها التالية |
| **سحب وإفلات** | اسحب مهمة إلى أي يوم في التقويم |
| **تراجع** | كل حذف/نقل/تكرار قابل للتراجع |
| **متأخّر تلقائيًا** | ما لم يُنجَز من أيام سابقة يظهر في خطة اليوم |
| **عربي/إنجليزي · ليل/نهار** | من قائمة واحدة (⋯) |
| **تصدير** | JSON و ICS |
| **بلا إنترنت** | service worker + manifest، قابل للتثبيت |

### اختصارات

`N` مهمة جديدة · `⌘/Ctrl + K` بحث · `T` اليوم · `←/→` الشهر · `Esc` إغلاق

## قواعد التصميم | Design rules

لونان فقط على أرضية كريمية: **#92A9E1** و **#2B2B2B**. لا ألوان تنبيه، لا شارات ملوّنة.

- **كتلة واحدة لكل معنى.** رأس اليوم كتلتان تفصلهما فجوة بمنحنى مقعّر (`mask: radial-gradient`) — نفس لغة الصورة المرجعية.
- **لا كلمات حيث تكفي الحالة.** لا وسوم «مهم/موعد/تصنيف» في القائمة: الدائرة الأثقل = مهم، الشرطة = منجز، التاريخ الغامق = متأخّر.
- **لا نصوص داخل خلايا التقويم.** نقاط فقط — العناوين تُقرأ في اللوحة المجاورة.
- **زر واحد بدل عنقود.** كل الإعدادات خلف زر (⋯).
- **الوضع الداكن يقلب دور الجرافيت** إلى كريم، فيبقى التباين ثنائي اللون في السِمَتين.

## البنية | Architecture

```
nidham/
├── index.html            الهيكل فقط
├── assets/css/app.css    متغيّرات لونية + سِمتان
├── assets/js/core.js     تواريخ + نصوص + مخزن + محلّل اللغة الطبيعية
├── assets/js/app.js      العرض والأحداث
├── sw.js                 عمل دون اتصال
├── tools/build.py        دمج في ملف واحد
└── dist/index.html       الناتج المستقل
```

**قرارات مقصودة:**

- **بلا إطار عمل ولا خطوة بناء.** جافاسكربت عادية تُقرأ بعد سنة.
- **نوع واحد للعنصر.** لا فصل بين «مهمة» و«موعد» — وقت اختياري ونهاية اختيارية.
- **`localStorage` لا خادم.** ملكية كاملة مقابل عدم المزامنة؛ التصدير يسدّ الفجوة.
- **تواريخ نصّية محلية `YYYY-MM-DD`** لا `toISOString()` (ينقل اليوم للخلف في التوقيتات الموجبة).
- **`\b` لا يعرف العربية في جافاسكربت**، فالمحلّل يستعمل `(?:^|\s)…(?=\s|$)`.

### حدود معروفة

- لا مزامنة بين الأجهزة (بالتصميم).
- التكرار يولّد النسخة التالية عند الإنجاز فقط.
- ICS تصدير فقط، بلا استيراد.
- مسح بيانات المتصفح يمسح كل شيء — صدّر نسخة أحيانًا.
