# موقع العملاء — aboal3z.dzn

موقع ثابت بالكامل: صفر بناء، صفر تبعيات، صفر أوامر. ارفع محتويات هذا
المجلد كما هي على أي استضافة.

## الرفع

**استضافة عادية (cPanel أو FTP):** ارفع كل ما في هذا المجلد إلى
`public_html` — أو إلى مجلد فرعي إن أردت الموقع على `/site`.

**Netlify أو Vercel أو Cloudflare Pages:** اسحب المجلد إلى صفحة النشر.
لا تضبط أمر بناء ولا مجلد إخراج — الملفات جاهزة كما هي.

**GitHub Pages:** ادفع المجلد وفعّل Pages على الفرع.

## الاتصال

`config.local.js` يحمل رابط قاعدة البيانات ومفتاحها العام، وهو **مربوط
مسبقاً** بمشروعك على Supabase. لا تحتاج تعديله.

المفتاح `anon` مفتاح **عام** مصمَّم ليعيش في المتصفح — ظهوره في مصدر
الصفحة طبيعي ولا يشكّل خطراً. حمايتك الحقيقية سياسات RLS داخل قاعدة
البيانات: الزائر يقرأ المنشور فقط، ويُنشئ طلباً، ولا يقرأ الطلبات.

## من أين يأتي المحتوى

كل نص وصورة وبكج وعمل يأتي من قاعدة البيانات ويُحرَّر من لوحة المشرف.
لا يوجد محتوى مكتوب في الكود.

قسم بلا بيانات لا يُعرض فارغاً: يظهر بحالة واضحة أو يختفي كلياً.

## المتصفحات

- Chrome و Edge و Opera: الزجاج بانكسار حقيقي عبر مرشّحة SVG.
- Safari و Firefox: زجاج بضبابية وحافّة مضيئة — أخفّ قليلاً، وكل شيء
  آخر يعمل كما هو.
- بلا JavaScript: تظهر رسالة تطلب تفعيله مع رابط تواصل مباشر.
