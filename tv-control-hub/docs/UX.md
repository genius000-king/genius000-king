# تجربة الاستخدام والصفحات

## المبادئ
1. **صفحة لكل وظيفة.** لا شاشة تجمع الريموت والملفات والمعلومات.
2. **الإفصاح التدريجي**: كل قسم يفتح على قائمة قصيرة (≤ 5 بطاقات). الخيارات الثانوية في لوحة سفلية (`GlassSheet`) أو قائمة.
3. **لا أكثر من 4 أفعال ظاهرة** في أي لحظة. الباقي خلف ⋯.
4. **الحالة بكلمة + لون** (`StatusDot`) — لا لون وحده.
5. **صفر خطوات متكررة**: الاتصال بآخر تلفزيون تلقائي عند فتح التطبيق.
6. الهوية من ملف عملاق حرفيًا: فحمي `#0A0A0A`، كريمي `#F1F0EC`، زجاج 58%/72%، بلور 16/18dp، بطاقات 22dp، كبسولات 52/40dp، خط IBM Plex Sans Arabic، خلفية حجرية بغيوم وحبيبات، طمس ما تحت النوافذ 18dp.
7. الاتجاه يتبع اللغة: عربي ← RTL، English ← LTR.

## الجوال — الملاحة
شريط سفلي زجاجي عائم بخمسة أقسام. كل قسم له صفحات فرعية مستقلة.

```
الرئيسية ─┬─ حالة الاتصال (بطاقة التلفزيون + زمن الاستجابة)
          ├─ 4 أفعال سريعة: الشاشة · الريموت · الكيبورد · التطبيقات
          └─ ملخص الجهاز: RAM · التخزين · الحرارة · مدة التشغيل

التحكم ───┬─ الشاشة المباشرة   (ملء الشاشة، أفقي، لمس/Trackpad، الجودة في لوحة)
          ├─ الريموت           (حلقة أسهم + رجوع/رئيسية + صوت + وسائط | وضع إيماءات)
          ├─ الماوس            (Touchpad، نقر، سحب بإصبعين للتمرير)
          ├─ الكيبورد          (نص يتزامن مع حقل التلفزيون، إدخال، مسح)
          └─ الاختصارات        (أزرار مخصصة: تسلسل مفاتيح أو فتح تطبيق)

الجهاز ───┬─ نظرة عامة (مباشر)
          ├─ المعالج · الرسوميات · الذاكرة · التخزين · الشبكة
          └─ الأداء (رسوم لحظية)

الأدوات ──┬─ التطبيقات   (تشغيل/إزالة، «انقل من جوالي»، «أرسل APK»)
          ├─ الملفات     (تصفح، رفع، تنزيل، نسخ/نقل/حذف/إعادة تسمية)
          ├─ الخدمات     (Node/Python: تشغيل/إيقاف/إعادة، Logs، المشاريع)
          └─ الطرفية     (Shell محدود | Termux)

الإعدادات ┬─ الاتصال (التلفزيون الحالي، اتصال يدوي)
          ├─ الأجهزة المقترنة
          ├─ الأمان (بصمة الجهاز، الصلاحيات الممنوحة)
          ├─ المظهر (داكن/فاتح/النظام، العربية/English)
          └─ حول + التشخيص
```

## التلفزيون — الملاحة
شريط جانبي زجاجي (يتحرك بالريموت) + محتوى. التركيز (Focus) واضح: تكبير 1.05 + إطار كريمي.

```
الرئيسية          حالة الخادم، IP، قائمة إعداد (Accessibility، التثبيت، الملفات، Termux)
إقران جوال        "افتح التطبيق على جوالك — سيظهر هذا التلفزيون تلقائيًا" + طلبات معلّقة
الأجهزة الموثوقة  قائمة ← تفاصيل ← إلغاء الوصول
الأذونات          لكل جهاز: شاشة · إدخال · ملفات · تطبيقات · طرفية · خدمات
الخدمات النشطة    البث، الأجهزة المتصلة الآن، خدمات Termux
الإعدادات         اسم الجهاز، المظهر، اللغة، المشغّل، ماوس الريموت، التشغيل عند الإقلاع
وضع المشغّل       (شاشة كاملة مستقلة) شبكة التطبيقات بهوية عملاق
```

### نافذة الموافقة على التلفزيون
تظهر فوق أي تطبيق (المحتوى تحتها مطموس). زر «سماح» مركّز افتراضيًا ← **ضغطة OK واحدة**.

### وضع المشغّل
- شريط علوي: الوقت والتاريخ · الشبكة · جوال متصل · الماوس · الإعدادات
- كبسولة بحث
- صف المفضلة
- شبكة كل التطبيقات، تبويبات: الكل · للتلفزيون · للجوال
- ضغطة مطوّلة على تطبيق ← لوحة: فتح · مفضلة · معلومات · إزالة
- فتح تطبيق جوال ← اقتراح تفعيل الماوس تلقائيًا
