# تجربة الاستخدام — «سطح واحد»

> من هوية عملاق نأخذ **المواد فقط**: الخلفية الحجرية، الزجاج والبلور، الألوان، الخط، شكل الكبسولة.
> التقسيم والترتيب والملاحة هنا **خاصة بهذا التطبيق** ولا تشبه عملاق.

## القواعد
1. **الحركة بدل الزر.** إن أمكن تنفيذ الفعل بإيماءة، لا نرسم له زرًا.
2. **التلقائي بدل الإعداد.** إن أمكن أن يقرر التطبيق، لا نسأل المستخدم.
3. **أقصى 3 أزرار ظاهرة** في أي شاشة.
4. **كل انتقال متحرك**: البطاقة تتمدد لتصبح صفحة، والصفحة تنكمش عائدة لمكانها. نوابض (spring) لا خطوط زمنية جامدة.
5. أول استخدام فقط: تلميح متحرك يوضح الإيماءة ثم يختفي للأبد.

## ما يحدث تلقائيًا (بلا أي ضغطة)
| | |
|---|---|
| الاتصال | يفتح التطبيق ← يتصل بآخر تلفزيون فورًا. انقطع؟ يعيد الاتصال وحده |
| الإقران | يظهر التلفزيون وحده. ضغطة OK على الريموت ← انتهى، للأبد |
| الكيبورد | يركّز التلفزيون على حقل نص ← كيبورد الجوال يفتح وحده، ويُغلق وحده |
| الصوت | أزرار الصوت الفعلية في الجوال تتحكم بصوت التلفزيون |
| جودة البث | تتكيف مع الشبكة وحدها. لا زر جودة |
| الماوس | فتح تطبيق جوال على التلفزيون ← يظهر المؤشر وحده |
| المراقبة | تعمل فقط عند النظر إليها (لا استهلاك للتلفزيون في الخلفية) |
| التشغيل | خدمة التلفزيون تبدأ مع الإقلاع |

## الجوال

### الشاشة الرئيسية = الريموت الحي
```
┌──────────────────────────────┐
│   ( ● Xiaomi TV · 12ms )     │  ← كبسولة الحالة. لمسها = نبض الجهاز
│                              │
│                              │
│        مساحة الإيماءات        │  ← خلفيتها: شاشة التلفزيون نفسها، مطموسة
│     اسحب = أسهم · انقر = OK   │     (أو الحجر إن لم يكن البث متاحًا)
│  مطوّل = قائمة · انقر مرتين = ⏯ │
│                              │
│                              │
│      (↩)      (⌂)      (⋯)    │  ← ثلاثة فقط: رجوع · رئيسية · المزيد
└──────────────────────────────┘
```
- الإصبع يترك أثرًا كريميًا ناعمًا، والسهم المنفّذ يومض باتجاهه.
- إمساك السحب = تكرار السهم بتسارع (للتمرير في القوائم الطويلة).
- **فتح الإصبعين (pinch‑out)** على المساحة ← الشاشة المباشرة.

### «المزيد» — لوحة تصعد من الأسفل
ست بطاقات كبيرة، أيقونة وكلمة فقط:
```
 الشاشة    الماوس    الجهاز
 التطبيقات  الملفات   الخدمات            ⚙
```
البطاقة المختارة **تتمدد** لتصبح صفحتها.

### الصفحات
| الصفحة | الشكل | الأزرار الظاهرة |
|---|---|---|
| **الشاشة** | الفيديو يملأ الشاشة، يدور أفقيًا وحده، اللمس مباشر على التلفزيون. كبسولة صغيرة تظهر عند لمس الحافة ثم تختفي | رجوع · كيبورد · خروج |
| **الماوس** | الشاشة كلها Touchpad. نقرة = نقر، إصبعان = تمرير، مطوّل = سحب | لا شيء |
| **الجهاز** | حلقة كبيرة للذاكرة + أرقام حية. البطاقات تتمدد مكانها للتفاصيل (المعالج، الرسوميات، التخزين، الشبكة). ما لا يتيحه Android يُكتب «غير متاح» وسببه | لا شيء |
| **التطبيقات** | شبكة أيقونات تطبيقات التلفزيون. لمسة = تشغيل على التلفزيون، مطوّل = إزالة/معلومات | «انقل من جوالي» |
| **الملفات** | تصفح بالمجلدات. لمسة = فتح، مطوّل = تحديد ← يظهر شريط الأفعال وقتها فقط | رفع |
| **الخدمات** | بطاقة لكل خدمة بمفتاح تشغيل كبير. لمسها = السجلات. الطرفية بطاقة أخيرة | إضافة |
| **الإعدادات** | قائمة قصيرة: التلفزيونات المقترنة، المظهر، اللغة، الأمان | — |

## التلفزيون

### الشاشة الوحيدة
```
                     21:47
                 الأربعاء 25 أكتوبر

        ◉ جاهز — افتح TV Hub على جوالك
          (أو: صورة رمزية لكل جوال متصل، تنبض)

   [ الأجهزة ]  [ الخدمات ]  [ المشغّل ]  [ الإعدادات ]
```
- قائمة الإعداد (Accessibility…) **تظهر فقط إن نقص شيء**، وتختفي عند اكتماله.
- لا صفحة «إقران»: نافذة الموافقة تظهر وحدها فوق أي تطبيق — المحتوى تحتها مطموس، و«سماح» مركّز ← **OK واحدة**.
- الأجهزة: كل جهاز ← صلاحياته كمفاتيح تشغيل + «إلغاء الوصول».

### وضع المشغّل
- الوقت كبير في الزاوية، لا شيء آخر في الأعلى.
- **صف واحد** من التطبيقات المفضلة بأيقونات كبيرة في المنتصف.
- **سهم للأسفل** ← كل التطبيقات تصعد بنابض (تلفزيون + جوال معًا).
- مطوّل على تطبيق ← مفضلة · إزالة.
- فتح تطبيق جوال ← المؤشر يظهر وحده؛ ضغطة مطوّلة على OK تبدّل الماوس يدويًا.
